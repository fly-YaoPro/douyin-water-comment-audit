# 抖音水评清理

按发布日期筛选视频，抽检公开评论，生成问题作品表并经确认分机构通知。

## 怎么用

“查水表，2026-09-01 至 2026-09-09”。

入口与完整规则：[SKILL.md](SKILL.md)。将整个仓库放入 AI 客户端的 Skills 目录，保持脚本和参考资料的相对路径。

## 在流程里的位置

默认包含独立端；主表按项目区分工作任务与课程教学。来源失败不能报零条成功；先估时确认，再抓取。

## 运行条件

这是豆尼业务 Skill 包，不是完整豆尼服务的安装包。自动写表、卡片回调、持久化台账及定时执行依赖豆尼工程的现有执行器；仅下载本仓库不能启动这些服务。

数据源和字段映射从豆尼工程 `config/business-sources.json` 读取，共用业务口径在 `config/business-policy.json`；定时任务由后台调度器维护。运行前在工程目录执行 `node scripts/business-context.mjs --skill douyin-water-comment-audit`，不要从旧示例地址猜当前数据源。

飞书、内容平台使用使用者自己的有效授权；写表、对外发送及其他需确认动作仍按 Skill 的门禁执行。仓库公开不等于飞书文档公开，也不代表共享维护者账号。
